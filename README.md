# README  

This repository contains the implementation accompanying the paper:  

**On the optimal selection of generalized Nash equilibria in linearly coupled aggregative games**  
*Emilio Benenati, Wicak Ananduta, Sergio Grammatico*  
*2022 IEEE 61st Conference on Decision and Control (CDC)*  
DOI: [10.1109/CDC51059.2022.9993415](https://doi.org/10.1109/CDC51059.2022.9993415)  

## Description  
The code implements methods to compute Generalized Nash Equilibria (GNE) in monotone aggregative games using the Restarted HSDM (Hybrid Steepest Descent Method).

To execute the code, run `main.py`.
